# 롤 5대5 실시간 밴픽

**한국어** | [English](README.en.md)

리그 오브 레전드 내전·스크림용 **실시간 밴픽(드래프트) 프로그램**입니다.
한 사람이 프로그램을 켜고 양 팀 주장에게 초대 링크를 보내면, 두 주장이 각자 브라우저에서 대회와 같은 순서로 밴픽을 진행합니다.

주장은 아무것도 설치하지 않아도 되고, 회원가입이나 로그인도 없습니다.

## 이런 때 씁니다

- 클랜·친구끼리 5대5 내전을 할 때, 게임 안의 밴픽 대신 대회 방식으로 진행하고 싶을 때
- 한 명이 화면을 공유(디스코드 등)하고 나머지는 그 화면으로 구경하는 방식으로 진행할 때
- 여러 세트를 이어서 하면서 피어리스 규칙과 세트 스코어를 관리하고 싶을 때
- OBS로 방송하면서 중계 화면 같은 밴픽 띠를 얹고 싶을 때

## 주요 기능

- **대회 방식 순서**: 팀당 밴 3 → 픽 3 → 밴 2 → 픽 2, 총 20단계
- **차례별 제한 시간**: 화면 맨 위에서 양끝이 가운데로 줄어드는 시간 바
- **시간 초과 시 경기 중단**: 자동 선택 없이 모두에게 중단 창이 뜨고, 진행자가 재개하거나 다시 시작
- **피어리스**: 이전 세트에서 픽한 챔피언 재사용 금지
- **시리즈 관리**: 3판 2선승 / 5판 3선승, 세트 승리 기록과 스코어 표시
- **방송 화면**: 화면 아래 중계 형식 띠, OBS용 투명 배경 전용 화면
- **5개 언어**: 한국어, 영어, 일본어, 중국어 간체, 러시아어 (접속자마다 따로 선택)
- **IP 노출 최소화**: 주소는 화면에 표시되지 않고 복사 버튼으로만 전달, 관전 링크 없음

## 빠른 시작 (Windows)

1. [Releases](../../releases/latest)에서 `lol-banpick.exe`를 받습니다.
2. 더블클릭해서 실행합니다. Node.js 설치는 필요 없습니다.
3. 검은 창이 뜨고 브라우저가 열립니다. **검은 창을 닫으면 서버가 꺼집니다.**

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
코드 서명이 없는 개인 제작 프로그램이라 뜨는 경고입니다. 소스는 이 저장소에 전부 공개되어 있습니다.

다른 사람이 외부에서 접속하려면 [외부 접속 설정](#외부-접속-설정)을 한 번 해야 합니다.

## 사용 방법

### 1. 방 만들기

브라우저에 뜬 화면에서 팀 이름, 차례당 제한 시간, 시리즈 방식, 피어리스 여부를 정하고 **방 만들기**를 누릅니다.
방을 만든 사람이 **진행자**가 됩니다.

### 2. 주장 초대

화면 아래 **초대 링크**를 펼치면 버튼이 세 개 있습니다.

| 버튼 | 누구에게 |
|---|---|
| 블루 주장 초대 링크 | 블루 팀 주장에게 개인 메시지로 |
| 레드 주장 초대 링크 | 레드 팀 주장에게 개인 메시지로 |
| 방송 전용 화면 | 진행자 자신의 OBS에 (선택) |

**링크 복사** 버튼을 누르면 클립보드에 복사됩니다. 주소는 화면에 표시되지 않습니다.

### 3. 밴픽 진행

1. 양 팀 주장이 접속하면 팀 이름 아래에 "주장 접속 중"이 표시됩니다.
2. 진행자가 **드래프트 시작**을 누르면 시간이 흐르기 시작합니다.
3. 주장은 자기 팀 차례에 챔피언을 클릭하고 **확정**을 누릅니다. 더블클릭하면 바로 확정됩니다.
4. 밴 차례에는 **밴 없음**도 고를 수 있습니다.
5. 검색창에서 이름이나 초성(ㅇㄹ → 아리)으로 찾고, 포지션 버튼으로 걸러 볼 수 있습니다.

### 4. 세트가 끝나면

게임이 끝나면 진행자가 하단의 **○○ 승리** 버튼을 누릅니다.
가운데 네모가 한 칸 채워지고 다음 세트로 넘어갑니다. 선승 수를 채우면 시리즈가 끝나고 승리 팀이 표시됩니다.

진영을 바꾸려면 세트 사이에 **진영 교체**를 누릅니다. 팀 이름, 선수 이름, 스코어, 주장 링크가 함께 반대편으로 넘어가므로 주장은 링크를 다시 받을 필요가 없습니다.

### 역할별 권한

| 역할 | 할 수 있는 일 |
|---|---|
| 진행자 | 시작, 재개, 되돌리기, 세트 승리 기록, 진영 교체, 옵션 변경, 모든 차례 대신 선택 |
| 주장 | 자기 팀 차례에 선택·확정, 자기 팀 이름과 선수 이름 변경 |
| 방송 화면 | 보기만 가능 |

진행자가 한쪽 주장을 겸할 때는 진행자 화면에서 자기 팀 차례에 직접 고르면 됩니다.

## 규칙

- **제한 시간**: 차례마다 정해진 시간(20/30/45/60초) 안에 확정하지 못하면 **경기 중단** 창이 모두에게 뜹니다. 자동으로 고르거나 넘어가지 않습니다. 진행자가 "이 차례부터 재개" 또는 "이번 세트 다시"를 고릅니다.
- **시간 바**: 차례인 팀 색으로 표시되고, 10초 이하가 되면 노란색으로 바뀝니다.
- **피어리스**: 켜면 다음 세트부터 이전 세트에서 픽한 챔피언을 고를 수 없습니다. 밴한 챔피언은 해당하지 않습니다.
- **되돌리기**: 진행자가 마지막 선택을 한 단계씩 취소할 수 있습니다.
- **스코어 고치기**: 승리 버튼을 잘못 눌렀으면 진행자가 가운데 네모 칸을 직접 눌러 고칩니다. 이미 넘어간 세트를 되돌리는 기능은 없습니다.

## 방송 화면

밴픽 화면 아래에 중계 형식의 가로 띠가 함께 표시됩니다. 하단의 "방송 화면 숨기기"로 끌 수 있습니다.

- **위쪽**: 양 팀 밴, 가운데는 피어리스에서 이전 세트에 쓴 챔피언(시리즈 밴)
- **아래쪽**: 블루 픽 5칸 · 가운데 정보(팀 이름, 세트 스코어, 차례 화살표, 남은 시간) · 레드 픽 5칸
- **선수 이름**: 픽 칸 아래 입력란에 적습니다.
- **방송 전용 화면**: 초대 링크의 "방송 전용 화면" 주소는 띠만 표시하고 배경이 투명합니다. 진행자 PC의 OBS 브라우저 소스에 넣어 씁니다.

## 언어

- 화면 하단(방 만들기 화면에서는 맨 위)의 언어 선택으로 바꿉니다. 선택은 그 브라우저에 저장됩니다.
- 처음 접속하면 브라우저 언어를 따릅니다. 링크 끝에 `&lang=ko|en|ja|zh|ru`를 붙이면 그 언어로 열립니다.
- 언어는 접속한 사람마다 따로 적용됩니다. 진행자가 한국어로 보고 있어도 주장은 영어로 볼 수 있습니다.
- 챔피언 이름도 선택한 언어로 표시됩니다. 검색은 현재 언어, 영어, 한국어(초성 포함) 이름 모두로 됩니다.
- 팀 이름을 비워 두면 보는 사람의 언어로 "블루 팀 / Blue Team"처럼 표시됩니다.
- 실행 창(검은 창)의 안내는 한국어와 영어만 지원합니다.

번역 수정이나 언어 추가는 환영합니다. `public/index.html`의 `I18N`과 `LANGS`, `server.js`의 `LOCALES`를 고치면 됩니다. 빠진 문구는 영어로 표시됩니다.

## 외부 접속 설정

같은 집 안에서만 쓸 때는 필요 없습니다. 다른 곳에 있는 주장이 접속하려면 아래 둘 중 하나를 합니다.

### 방법 1. 포트포워딩 (기본)

1. **공유기 포트포워딩**: 외부 TCP 3000 → 서버 PC 내부 IP의 TCP 3000. 내부 IP는 검은 창의 "같은 공유기 안에서" 줄에 나옵니다.
2. **Windows 방화벽**: 처음 실행할 때 뜨는 창에서 "액세스 허용"을 누릅니다. 창을 놓쳤다면 방화벽 인바운드 규칙에 TCP 3000을 추가합니다.

설정이 됐는지는 휴대폰 LTE/5G처럼 **다른 회선**에서 확인하세요. 같은 공유기 안에서는 공인 IP로 접속이 안 되는 공유기가 많습니다.

### 방법 2. 포트를 열지 않고 쓰기 (터널)

1. Cloudflare 공식 배포판에서 `cloudflared-windows-amd64.exe`를 받아 `lol-banpick.exe`와 같은 폴더에 둡니다.
2. `config.json`에서 `"tunnel": true`로 바꾸고 다시 실행합니다.

초대 링크가 임시 주소(`trycloudflare.com`)로 만들어집니다. 포트 개방이 필요 없고 링크에 IP도 들어가지 않습니다.
주소는 프로그램을 켤 때마다 바뀌며, Cloudflare가 체험용으로 제공하는 기능이라 가동이 보장되지는 않습니다.

## IP 노출에 대해

이 프로그램은 진행자의 PC가 서버가 되는 구조라서, 노출을 줄이도록 다음과 같이 만들었습니다.

- 초대 링크 주소는 화면 어디에도 표시되지 않고 복사 버튼으로만 전달됩니다.
- 실행 창에서도 공인 IP는 가려집니다.
- 진행자는 `localhost`로 접속하므로 화면을 공유해도 주소창에 IP가 보이지 않습니다.
- 관전 링크가 없습니다. 키 없이 주소만 알고 들어온 접속은 서버가 거부합니다.

**남는 노출**: 포트포워딩 방식에서는 주장 링크 자체에 서버 주소(공인 IP)가 들어 있습니다. 링크를 받은 주장 두 명은 IP를 알 수 있으니 개인 메시지로만 보내세요. 주장에게도 감추려면 위의 터널 방식을 쓰면 됩니다.

## config.json

처음 실행하면 exe와 같은 폴더에 만들어집니다. 고친 뒤 프로그램을 다시 실행하세요.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `port` | 3000 | 접속 포트. 바꾸면 공유기 포트포워딩도 같은 번호로 맞춥니다. |
| `publicHost` | 비어 있음 | 초대 링크에 쓸 주소. 비워 두면 공인 IP를 자동으로 찾습니다. 공인 IP가 자주 바뀌면 DDNS 도메인을 적어 두세요. |
| `showPublicIp` | false | true로 하면 실행 창에 공인 IP를 그대로 표시합니다. |
| `tunnel` | false | true로 하면 포트 개방 없이 쓰는 임시 주소를 만듭니다. |
| `lang` | 비어 있음 | 실행 창 안내 언어(`ko` 또는 `en`). 비워 두면 Windows 언어를 따릅니다. |

## 자주 묻는 질문

**실행했는데 "Windows의 PC 보호" 창이 떠요.**
코드 서명이 없는 프로그램이라 뜨는 경고입니다. "추가 정보 → 실행"을 누르면 됩니다.

**챔피언 그림이 안 나오고 이름만 나와요.**
서버 PC가 라이엇 Data Dragon에 접속하지 못한 경우입니다. 인터넷 연결을 확인하고 다시 실행하세요. 이름만으로도 밴픽은 진행됩니다.

**새로 나온 챔피언이 없어요.**
목록은 실행할 때와 6시간마다 Data Dragon에서 새로 받아옵니다. 프로그램을 다시 실행해 보세요. 새 챔피언이 포지션 필터에 안 잡히면 `champions.js`에 `이름:포지션`을 추가해야 합니다(전체 목록과 검색에는 나옵니다).

**"3000번 포트를 다른 프로그램이 쓰고 있습니다"라고 나와요.**
`config.json`의 `port`를 다른 번호로 바꾸고, 공유기 포트포워딩도 같은 번호로 맞추세요.

**주장이 링크로 들어왔는데 "들어올 수 없습니다"가 떠요.**
링크가 중간에 잘렸거나, 서버를 껐다 켜서 방이 사라진 경우입니다. 방을 새로 만들고 링크를 다시 보내세요.

**서버를 껐다 켜면 진행 중이던 방은요?**
사라집니다. 방 상태는 메모리에만 있습니다. 아무도 접속하지 않은 방은 12시간 뒤 삭제됩니다.

## 소스에서 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
npm test           # 서버를 띄운 상태에서 전체 동작 점검 (약 6초)
npm run build:exe  # dist/lol-banpick.exe 만들기
```

HTTPS 뒤(Nginx, Caddy 등)에 둘 때는 WebSocket 업그레이드가 `/ws` 경로로 전달되어야 합니다.

### 파일 구성

| 파일 | 내용 |
|---|---|
| `server.js` | HTTP + WebSocket 서버, 밴픽 규칙과 타이머, 실행 창 안내 |
| `champions.js` | 내장 챔피언 목록(접속 실패 시 대체용)과 포지션 표 |
| `public/index.html` | 화면 전체와 5개 언어 번역 |
| `test.js` | 방 생성부터 권한, 20단계 진행, 시간 초과 중단, 시리즈까지 점검 |

### 챔피언 데이터

서버가 시작할 때 라이엇 Data Dragon에서 최신 패치의 챔피언 목록을 5개 언어로 받아오고, 6시간마다 새 패치를 확인합니다.
접속하지 못하면 `champions.js`의 내장 목록을 쓰며, 이때는 그림 없이 한국어 이름만 표시됩니다.
